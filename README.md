# SpringEduManager 🎓

Una aplicación web desarrollada en Java con Spring Boot para la gestión de estudiantes y cursos. Este proyecto implementa una arquitectura sólida y segura, ideal para demostrar competencias en el desarrollo Backend moderno.

## 🚀 Características Principales

* **Arquitectura MVC:** Separación clara entre Modelo, Vista y Controlador.
* **Seguridad:** Autenticación y protección de rutas implementada con Spring Security.
* **Base de Datos Embebida:** Uso de H2 Database para persistencia ágil en memoria mediante JPA/Hibernate.
* **Interfaz Moderna:** Vistas HTML dinámicas generadas con Thymeleaf y estilizadas de forma responsiva con Bootstrap 5.
* **API RESTful:** Endpoints configurados para la interoperabilidad y consumo de datos en formato JSON.

## 🛠️ Tecnologías Utilizadas

* Java
* Spring Boot & Maven
* Spring Data JPA
* H2 Database
* Spring Security
* Thymeleaf
* Bootstrap 5

1. Clona este repositorio en tu máquina local.
2. Abre la terminal en la raíz del proyecto.
3. Ejecuta el servidor utilizando el wrapper de Maven:
